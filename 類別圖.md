# 類別圖

```mermaid
classDiagram
    class AbstractDataReader {
        +read(columns, filters, limit) DataFrame
    }

    class BaseSqlDataReader {
        -Path database_path
        +database_path
        +_validate_limit(limit)
    }

    class SQLiteDataReader {
        -str _table_name
        +read(...)
        +_build_query(...)
    }

      class KbarPipelineController {
          -AbstractDataReader _data_reader
          -KbarDataValidator _validator
          -KbarDataProcessor _processor
          -KbarDataFiller _filler
          +run(columns, filters, limit) PipelineArtifacts
      }

      class PipelineArtifacts {
          +raw_frame: DataFrame
          +timezone_aligned_frame: DataFrame
          +filled_frame: DataFrame
          +validation_report: ValidationReport
      }

    class KbarDataProcessor {
        -TimestampProcessingConfig _config
        +process(frame, inplace)
        +convert_timezone(frame, inplace)
    }

    class KbarDataValidator {
        +validate(frame) ValidationReport
    }

    class KbarDataFiller {
        +fill(frame) DataFrame
    }

    class ValidationReport {
        +issues: Mapping
        +is_valid
        +total_invalid_rows
    }

    AbstractDataReader <|-- BaseSqlDataReader
    BaseSqlDataReader <|-- SQLiteDataReader
    ValidationReport <-- KbarDataValidator
      PipelineArtifacts --> ValidationReport
      KbarPipelineController --> AbstractDataReader : uses
      KbarPipelineController --> KbarDataValidator : uses
      KbarPipelineController --> KbarDataProcessor : uses
      KbarPipelineController --> KbarDataFiller : uses
      KbarPipelineController --> PipelineArtifacts : produces
```
