# 元件圖

此元件圖說明 CLI 執行流程中各模組的互動與邊界，維持鬆耦合架構以方便替換與測試。

```mermaid
graph TD
    subgraph 使用者端
        CLI[命令列介面]
    end

    subgraph 應用層
        Controller[BacktestController]
        ErrorHandler[ErrorHandler]
    end

    subgraph Domain層
        Strategy[MomentumStrategy]
        Reporter[ConsoleReporter]
    end

    subgraph 基礎設施層
        Gateway[SqliteKBarGateway]
        DB[(sample_kbars.db)]
    end

    CLI --> Controller
    Controller --> Gateway
    Gateway --> DB
    Controller --> Strategy
    Strategy --> Controller
    Controller --> Reporter
    Controller -.錯誤-> ErrorHandler
```
